项目名
 
HLTV 年度 Top20 If 线模拟器
 
一句话定位
 
用户自定义赛事结果和荣誉归属，系统按自定义权重算法重算全年 Top20，并与 HLTV 原版排名对比名次变化。
 
核心规则（已确认）
 
总分公式
选手总分 = ∑（单赛事表现分 × 赛事权重）
 
赛事权重默认值（用户可改）
赛事级别 默认权重
Major 1.0
超级精英赛 0.8~0.9
精英赛 0.75
大型赛事 0.65
中型赛事 0.5
次级赛事 0.45
不纳入 0

 
单赛事表现分默认规则（用户可改）
 
荣誉基础分：
• MVP：9~10，rating > 1.5 额外 +1，上限 11
• 第一 EVP：8
• 第二 EVP：6
• 第三 EVP：4
• 无荣誉：0
• 未参赛：0
• 表现极差：-1 
个人数据调整：
• 默认只有 rating > 1.5 加 1 分
• ADR、KPR 作为高级设置里的手动微调项 
队伍成绩调整（建议默认，可改）：
队伍成绩 调整
冠军 0
亚军 -1
四强 -2
八强 -3
小组淘汰 -5

 
最终表现分：
一般 0~10，特殊可到 -1 或 11。
 
If 线重算逻辑
1. 用户选年份、赛事
2. 设定 If 结果：谁夺冠、谁 MVP、EVP 怎么分
3. 原 MVP 处理方式由用户决定：
	• 保持 MVP
	• 降为 EVP
	• 移除荣誉
	• 转给其他人
4. EVP 自动重排：
	• 只对进入淘汰赛队伍的选手排序
	• 按该赛事表现数据从高到低
	• 取前三名作为第一、第二、第三 EVP
5. 个人数据不变
6. 系统重算全年总分并排序
7. 与 HLTV 原版 Top20 对比
8. 保存为本地存档，可创建多个 If 方案 
功能模块
1. Excel 数据导入：赛事、选手、荣誉、rating、队伍成绩
2. 权重配置：赛事级别权重可改，有默认值
3. 表现分计算器：按规则算单赛事分
4. If 线编辑器：改赛事结果、重分配 MVP/EVP
5. 重算引擎：全年总分重算、排序
6. Top20 对比页：名次升降、总分变化
7. 存档管理：本地保存多个 If 方案，可切换对比 
页面结构
• 首页 / 年份选择
• 赛事列表页
• If 线编辑页
• Top20 对比页
• 权重设置页
• 存档管理页 
数据结构草案
实体 关键字段
选手 ID、姓名、队伍、年份
赛事 名称、年份、级别、权重
赛事结果 选手、荣誉、rating、ADR、KPR、队伍名次
If 方案 年份、赛事、原结果、新结果、荣誉重分配
排名快照 年份、算法版本、Top20 列表、总分

 
技术建议
• 纯前端即可，不需要后端
• 前端：React / Vue + Vite + TypeScript
• 样式：Tailwind CSS
• Excel 解析：SheetJS
• 本地存储：IndexedDB（Dexie）或 localStorage
• 图表：ECharts / Recharts
• 部署：Vercel / Netlify 
开发阶段
1. 数据模型 + Excel 导入
2. 权重配置 + 表现分计算
3. If 线编辑器 + 重算引擎
4. Top20 对比展示
5. 存档管理 + 细节打磨 
重要说明
• 这是自定义算法模拟器，不是 HLTV 官方算法
• 对比时只展示 HLTV 原版排名，不重算原版
• 所有默认分值都可被用户覆盖
